# Журнал действий Personal AI Brain

## Назначение

`action_audit.py` фиксирует метаданные вызовов инструментов и отдельных операций Brain: название действия, тип события, решение политики автономности/инициатора, источник разрешения, основание решения, итог и длительность.

## Хранение

- По умолчанию: `~/.personal_ai_brain/audit/actions.jsonl`.
- Каталог создаётся с правами `0700`, файл — `0600` (где ОС поддерживает POSIX permissions).
- Записи добавляются построчно, с `O_APPEND` и `fsync`.
- Журнал находится вне репозитория и не должен попадать в Git.

## Граница данных

Журнал намеренно НЕ сохраняет аргументы инструмента, пользовательские запросы, содержимое файлов, результаты инструментов, память, промпты, API-ключи и другие секреты. Код ошибки нормализуется в ограниченный набор символов и длину.

## Ограничения первой версии

- Сейчас покрыты вызовы Tool Bridge, атомарные записи памяти и операции жизненного цикла задач. Изменения модулей, MCP, обновления, все CLI-команды и операции резервного копирования ещё не покрыты полностью.
- Это локальный append-only журнал на уровне приложения, а не криптографически защищённый tamper-proof ledger.
- Журнал не синхронизируется во внешнее хранилище.
- Ошибка записи журнала не должна превращать успешный вызов инструмента в ложный успех или ломать основной цикл; вызывающий код получает безопасный статус ошибки.
- Ротация, проверяемая цепочка хешей и экспорт с явным согласием — отдельные этапы.
- Шифрование резервных копий ещё не реализовано этим модулем.

## Проверка

`python -m unittest -v test_action_audit` проверяет метаданные, отсутствие содержимого/секретов и корректное добавление нескольких событий.
