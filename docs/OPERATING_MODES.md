# Режимы работы Brain

Режим действует до завершения текущего сеанса и не сохраняется между перезапусками. Команды:

```text
режим
режим общение
режим исследование
режим программирование
режим обучение
режим автономное исполнение
```

| Режим | Назначение | Набор инструментов |
|---|---|---|
| Общение | Обычный диалог, поведение по умолчанию | Существующий включённый набор |
| Исследование | Сбор и анализ сведений | Только чтение |
| Программирование | Анализ, редактирование кода и тесты | Чтение + file_edit/write_file/run_tests и инструменты предложений |
| Обучение | Пошаговое обучение и упражнения | Только чтение, без web_fetch и записи |
| Автономное исполнение | Выполнение явно запущенных сохранённых планов | Чтение + ограниченные операции записи/тестирования |

## Границы безопасности

- Режимы исследование и обучение не показывают модели изменяющие инструменты.
- Программирование и автономное исполнение допускают редактирование файлов, но не отменяют существующее подтверждение и политику автономности.
- Shell и публичная публикация скрыты в исследовательском, учебном, программном и автономном режимах.
- Даже если модель запросит инструмент, отсутствующий в текущем списке, Tool Bridge отклонит вызов по allowlist.
- Режим общения по умолчанию сохраняет текущую совместимость.
- Режимы меняют только доступность инструментов и инструкции; они не повышают права пользователя и не обходят разрешения.
