# Мобильная панель Brain

Команда `панель` или `dashboard` показывает компактную read-only сводку:
- состояние Brain, активную модель и провайдера;
- статистику запросов и количество Free-моделей;
- количество записей памяти и распределение по категориям;
- количество задач по статусам и высоким приоритетам;
- включённые инструменты;
- локальные модельные процессы и состояние MCP filesystem;
- количество ожидающих кандидатов памяти.

Панель предназначена для узкого экрана Termux. Она показывает только агрегаты: не выводит тексты памяти, задачи, запросы, аргументы инструментов, ключи и абсолютные пути. Команда не изменяет состояние и не запускает процессы.

Подробные действия остаются в отдельных командах `статус`, `задачи`, `задача <ID>`, `память`, `память карточка <ID>`, `предложения` и `selfcheck`.
