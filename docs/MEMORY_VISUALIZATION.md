# Просмотр памяти и происхождения записей

## Команды

- `память` — краткий список;
- `память показать` — полный список;
- `память найти <текст>` — поиск;
- `память карточка <ID>` — одна запись с источником и историей изменений;
- `память происхождение <ID>` — псевдоним карточки;
- `память кандидаты` — предложения, ожидающие решения;
- `память подтвердить <ID>` — отдельное явное подтверждение кандидата.

## Карточка памяти

Карточка показывает только одну однозначно найденную запись: текст, категорию, важность, тип, статус, источник, уверенность, даты, срок хранения и последние десять событий истории. В истории показываются действие, автор и изменённые поля; значения до/после не дублируются в диагностическом представлении.

Короткий ID, совпавший с несколькими записями, не раскрывает ни одну из них: требуется более длинный идентификатор. Просмотр использует read-only доступ к каноническому файлу, не создаёт его, не меняет записи и не выводит соседние записи.

## Предложения изменений

Очередь кандидатов остаётся отдельным этапом. Просмотр кандидатов не применяет изменения; перенос факта в память выполняется только после явной команды подтверждения. Для уточнения существующей записи сохраняется проверка ожидаемого старого текста и история изменений.
