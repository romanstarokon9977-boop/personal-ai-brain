# Personal AI Brain

Персональный AI-ассистент для Android / Termux с маршрутизацией языковых моделей, локальной памятью, инструментами, планированием задач и проверкой результатов.

> **Статус:** проект активно развивается. Наличие зелёного CI не означает, что все функции прошли проверку на POCO F6. Перед эксплуатацией изучите [реестр готовности продукта](docs/PRODUCT_READINESS.md).

## Архитектура

Основной поток обработки запроса:

1. Определение задачи и выбор модели.
2. Подготовка контекста и применение политики приватности.
3. Планирование и управление задачей при необходимости.
4. Проверка полномочий инструмента через Tool Registry и Autonomy Controller.
5. Выполнение native/MCP-инструмента.
6. Проверка результата через Verifier / Goal Verifier.
7. Сохранение разрешённых фактов и обратной связи в локальной памяти.

Основные компоненты:

| Компонент | Назначение |
|---|---|
| `brain.py` | Точка запуска, маршрутизация моделей и основной цикл |
| `memory/` | Память, извлечение фактов, резервирование и семантические проверки |
| `context_manager.py` | Бюджет и безопасная подготовка контекста |
| `context_personalization.py`, `chat_recall.py` | Контекст прошлых чатов по доменам |
| `planner.py`, `task_manager.py` | Планирование и сохранение прогресса |
| `execution_engine.py`, `verifier.py`, `goal_verifier.py` | Исполнение и проверка постусловий |
| `tool_registry.py`, `autonomy_controller.py` | Каталог инструментов и политика разрешений |
| `mcp_bridge.py` | Локальный MCP stdio bridge |
| `self_improvement/` | Диагностика качества и контролируемые предложения улучшений |

## Приватность

- Локальная память, межчатовый recall и пользовательские skill-дескрипторы добавляются в контекст только для явно локального маршрута.
- Если локальный маршрут завершается ошибкой, Brain не переключает этот запрос на внешний API автоматически; требуется отдельный выбор пользователя.
- Дополнительная проверка на границе `controller_execute()` удаляет эти блоки при переходе на внешний API, в том числе после fallback.
- Локальный embedding adapter принимает только loopback URL и не имеет удалённого fallback.
- Текущий запрос и обычная история активного диалога могут отправляться выбранному внешнему провайдеру. Не включайте в запрос данные, которые не хотите передавать этому провайдеру.
- API-ключи хранятся в переменных окружения. Не коммитьте ключи, локальные конфиги, файлы памяти или логи.

## Установка

Проверенные инструкции для Termux находятся в [docs/TERMUX_INSTALL.md](docs/TERMUX_INSTALL.md). Они описывают установку и prerequisites; фактическая совместимость локальных моделей и embedding-сервера должна быть подтверждена на целевом устройстве.

## Запуск

Из каталога репозитория после установки зависимостей и настройки `OPENROUTER_API_KEY`:

```bash
python brain.py
```

## Команды памяти

- `память` — краткий просмотр записей.
- `память статус` — агрегированная статистика.
- `память семантика` — локальный read-only предпросмотр кандидатов семантического объединения. Для команды требуется отдельный embedding endpoint на `127.0.0.1:8090`; сервер не запускается автоматически. Команда показывает текст кандидатов только в терминале и ничего не изменяет.

## Тестирование

CI проверяет Python 3.11 и 3.14. Локальный запуск тестов:

```bash
OPENROUTER_API_KEY=test-only-placeholder python -m unittest discover -v
```

Тесты используют заглушку API-ключа и должны работать без реального вызова OpenRouter. Для полного набора используйте Python 3.11 или 3.14, соответствующий вашей среде.

## Ограничения текущей версии

- В локальном режиме Brain пока отключает model tool-calling; локальная модель работает как чат, а не как полноценный агент с инструментами.
- Автоматическая интеграция локального embedding provider в обычный цикл запуска Brain ещё не завершена.
- Работа отдельного embedding-сервера на POCO F6 и его производительность не подтверждены.
- MCP server catalog пока не является универсальным runtime для произвольных внешних сервисов.
- Self-improvement формирует диагностику и предложения; он не означает автономное применение кода.
- CI не проверяет Android permissions, GGUF-файлы, нагрев, RAM или длительную стабильность телефона.
