# АУДИТ: закрытие shell-канала чтения (завершение security hardening)
Статус: [ПО ФАКТУ]

## Суть
cat и grep удалены из TOOL_ALLOWED_COMMANDS (9→7): shell больше не является
альтернативным каналом чтения файлов в обход FILES_ALLOWED_DIRS.
Модельный доступ к содержимому файлов — только через path-gated
read_file/file_search/write_file/file_edit (security_check путей).

## Остаточный риск (зафиксирован, принят)
- ls произвольных каталогов: имена файлов без содержимого
- ps: аргументы командных строк процессов
Принято: низкая чувствительность, удаление ls/ps ломало бы легитимные сценарии.
